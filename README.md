# Darshil Parekh — Personal Portfolio

A modern, responsive personal portfolio website designed to showcase my projects, skills, experience, and frontend development work.

## 🌐 About the Project

This portfolio was created to provide a simple and professional way to present my work and connect with potential clients, collaborators, and employers.

The website includes:

* 🏠 Hero / Introduction section
* 👨‍💻 About Me section
* 💼 Projects showcase
* 📄 Resume download
* 📩 Contact section
* 🔗 LinkedIn and GitHub links
* 📱 Responsive design for different screen sizes

The homepage introduces me as a freelance frontend developer and provides quick access to my work and contact information.

## 📱 Responsive Design

The portfolio is designed to work across desktop, tablet, and mobile screen sizes.

On smaller screens:

* The hero section changes to a single-column layout.
* Project cards become single-column.
* The About section becomes vertically stacked.
* The contact form adapts to smaller screen widths.
* Navigation links wrap when necessary.
